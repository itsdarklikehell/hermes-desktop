# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities by opening a [security advisory](https://github.com/itsdarklikehell/hermes-agent/security/advisories/new).

Do NOT open a public issue for security vulnerabilities.

We will acknowledge your report within 48 hours and work with you to understand and address the vulnerability.

## Scope

This security policy applies to the latest release of this project.
