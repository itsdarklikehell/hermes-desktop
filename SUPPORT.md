# Support

## How to get help

- **Documentation**: Check the [README](README.md) and [docs](docs/) directory
- **Issues**: Search existing [GitHub Issues](https://github.com/itsdarklikehell/hermes-agent/issues) before creating a new one
- **Discussions**: Use [GitHub Discussions](https://github.com/itsdarklikehell/hermes-agent/discussions) for questions

## What to include in a bug report

1. A clear description of the problem
2. Steps to reproduce
3. Expected vs actual behavior
4. Your environment (OS, version, etc.)
5. Relevant logs or error messages

## Response times

We aim to respond to issues within 48 hours, but this is not guaranteed. For urgent security issues, please use the security advisory process.
